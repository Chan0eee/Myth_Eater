# GDD Lite — Myth Eater (가제: 신화를 삼키는 자)

> 기획서. 수직 슬라이스 범위를 정의한다. 변경 시 이 파일을 먼저 고친다.
> 방향: 종스크롤 (세로 화면, 위로 상승)

## 한 줄
신들에게 계략에 빠져 힘을 잃은 '공허의 포식자'가 신화 속 존재들을 삼키며 힘을 되찾고,
약한 신부터 강한 신까지 100라운드를 정복해 올라가는 종스크롤 아케이드.

## 스토리
주인공은 우주의 끝에서 떠돌던 포식자. 제우스의 꾐에 빠져 올림포스의 연회에 초대받았다가
힘을 봉인당한 채 타르타로스 심연에 추방된다. 이제 신화의 존재들을 삼키며 힘을 되찾고,
신들의 전당을 향해 올라간다. 약한 신부터, 마지막엔 신들의 왕까지.
올림포스가 무너지자 이를 지켜보던 아스가르드의 신들이 봉인을 시도하며 라그나로크 편이 열린다.

## 코어 루프
1. 라운드 시작 시 동료 1명을 편성 (뽑기로 획득한 신 중 선택)
2. 화면이 자동으로 위로 스크롤. 터치 드래그로 포식자를 상하좌우 이동
3. 자신보다 작은 신화 생물을 삼키며 성장. 동료는 주변을 공전하며 자동으로 원소 공격
4. 배고픔 게이지: 시간이 지나면 감소, 0이 되면 서서히 체력 감소
5. 5라운드마다 중간보스, 10라운드마다 신 보스 처치 → 다음 구간으로
6. 100라운드(오딘) 클리어 → 다음 난이도 해금

## 조작 (모바일 퍼스트)
- 드래그: 포식자 상하좌우 이동 (상대 드래그, 손가락 가림 방지 오프셋)
- 탭: 짧은 대시 (쿨타임 3초) — 먹이 돌진 / 공격 회피용
- 세로 화면 고정 (portrait), 한 손 플레이

## 5원소 상성
모든 공격(동료·보스·장비)은 불/물/바람/대지/번개 중 하나의 속성을 가진다.
상성 사이클: **불 → 바람 → 대지 → 번개 → 물 → 불** (화살표 방향에 강함, 반대에 약함)

| 속성 | 강함 | 약함 |
|------|------|------|
| 불 | 바람 | 물 |
| 바람 | 대지 | 불 |
| 대지 | 번개 | 바람 |
| 번개 | 물 | 대지 |
| 물 | 불 | 번개 |

## 라운드 / 보스 구조 (100라운드, 신 10명)
- 5라운드마다 중간보스, 10라운드마다 신 보스가 등장
- 일반 라운드의 먹이는 다음 보스 구간의 테마 생물로 구성

| 라운드 | 중간보스 (고증) | 신 보스 (고증) | 신 속성 |
|--------|----------------|---------------|---------|
| 5 / 10 | 키클롭스 — 외눈 거인 대장장이 | **아레스** — 전쟁의 신. 무력은 강하나 지략이 부족해 첫 타겟으로 적절 | 불 |
| 15 / 20 | 메두사 — 아테나에게 저주받은 고르곤 | **아테나** — 지혜와 전략의 여신 | 번개 |
| 25 / 30 | 악타이온 — 아르테미스에게 사슴이 된 사냥꾼 | **아르테미스** — 사냥의 여신 | 바람 |
| 35 / 40 | 켈베로스 — 세 머리의 문지기 | **하데스** — 스틱스의 강을 다스리는 저승의 왕 | 물 |
| 45 / 50 | 피톤 — 아폴론이 델포이에서 쓰러뜨린 뱀 | **아폴론** — 태양의 신 | 불 |
| 55 / 60 | 기간테스 — 제우스에 맞선 거인족 | **제우스** — 번개의 신들의 왕. 그리스 편의 끝 | 번개 |
| 65 / 70 | 요툰 전사 — 서리 거인 | **토르** — 묠니르의 번개신. 대지 여신 요르드의 아들 | 대지 |
| 75 / 80 | 펜리르 — 로키의 아들 늑대 | **로키** — 변신과 분신의 트릭스터 | 바람 |
| 85 / 90 | 발키리 — 프레이야가 이끄는 전장의 처녀 | **프레이야** — 사랑과 전쟁의 여신. 바다에 흘린 눈물이 금이 된 전설 | 물 |
| 95 / 100 | 수르트 — 불의 거인. 세계를 태우는 자 | **오딘** — 궁니르와 까마귀 후긴·무닌. 최종 보스 | 번개 |

## 난이도
- **EASY → NORMAL → HARD → CHALLENGE** 4단계
- EASY 100라운드를 클리어해야 NORMAL 1라운드 해금 (이하 동일)
- 신은 추가하지 않고, 난이도별로 스탯 배율 상승 — 오래 즐기게 만드는 구조
- 배율 수치는 페이즈 2에서 확정

## 동료 뽑기 시스템 (가챠)
- 외계인은 배고파처럼 뽑기로 캐릭터를 모으고, 라운드마다 1명을 편성해 함께 싸운다
- 동료 풀은 **제우스와 반대편에 섰던 신화 속 인물** — 스토리와 직결
- 뽑기 연출: **타르타로스의 감옥 열기** — 제우스에게 갇힌 신들을 구출한다는 설정
- 보스를 쓰러뜨려도 동료 해금은 없음. **무조건 뽑기로만 획득**
- 보스로 등장하는 캐릭터(티폰·로키·펜리르)도 뽑기 풀에 별도로 존재 — 가챠 게임의 단골 문법

### 동료 로스터
| 캐릭터 | 고증 | 등급 | 속성 | 전투 역할 |
|--------|------|------|------|----------|
| 프로메테우스 | 인간에게 불을 준 죄로 처벌받은 반역의 상징 | 전설 | 불 | 화염 오라 — 주변 적 지속 피해 |
| 메티스 | 제우스한테 삼켜진 첫 아내, 지혜의 여신 | 전설 | 번개 | 지혜의 가호 — 성장 속도 증가 |
| 티폰 | 제우스를 한때 가둔 유일한 존재 | 전설 | 바람 | 폭풍 돌진 — 전방 범위 공격 |
| 크로노스 | 제우스의 아버지, 티탄의 왕 | 전설 | 대지 | 시간 왜곡 — 적 감속 |
| 아틀라스 | 하늘을 짊어진 티탄 | 희귀 | 대지 | 주기적 실드 |
| 헤라 | 일리아드에서 제우스를 묶으려 한 모반 가담 | 희귀 | 바람 | 먹이 자석 범위 증가 |
| 포세이돈 | 같은 모반 가담. 바다의 신 | 희귀 | 물 | 해일 범위 공격 |
| 로키 | 아스가르드의 적 (노르드) | 전설 | 불 | 분신 — 환영이 함께 공격 |
| 펜리르 | 오딘을 삼킬 운명의 늑대 (노르드) | 전설 | 대지 | 광폭화 — 처치 시 공속 증가 |

### 뽑기 설계 (수치는 페이즈 2에서 확정)
- 등급: 일반 / 희귀 / 전설, 천장(픽업 보장) 시스템, 중복 → 돌파(강화)

## 재화
| 재화 | 획득 | 용도 |
|------|------|------|
| 신화의 파편 (일반) | 먹이 섭취, 라운드 클리어 | 장비 강화 |
| **오딘의 금화** (프리미엄) | 현금 충전. 5/10라운드 보상·출석 이벤트·플레이 이벤트로도 소량 획득 | 뽑기(감옥 열기) 전용 |

## 장비 시스템
- 슬롯 9개: **무기 / 투구 / 장갑 / 갑옷 / 하의 / 신발 / 반지×2 / 목걸이**
- 장비에도 등급·속성 존재. 강화는 신화의 파편(일반 재화)으로
- 상세 스탯 설계는 페이즈 2에서

## 성장 단계
- Lv1 심연의 새끼 → Lv2 포식자 → Lv3 신화급 거대체
- 각 단계에서 비주얼이 커지고 입이 벌어짐 (스쿼시 앤 스트레치)

## 게임필 (game-feel 스킬 참조)
- 삼킴: 입 쩍 벌림 + 화면 미세 진동 + "꿀꺽" 파티클
- 성장: 레벨업 링 이펙트 + 짧은 슬로모(히트스톱)
- 피격: 화면 흔들림 + 붉은 비네트
- 보스전: 등장 시 이름 자막 + 체력 바 (외계인은 배고파식 연출)

## 아트 디렉션 (확정)
- **볼드 카툰 치비 스타일** (레퍼런스 외계인은 배고파 계열): 굵은 외곽선, 셀 셰이딩, 고채도 컬러, 치비 비율, 글로시 하이라이트.
- 스테이지마다 테마 컬러 (그리스: 대리석+올리브, 지하세계: 어둠+청록 불꽃, 노르드: 설원+오로라).
- ⚠️ IP 주의: 스타일(화풍)만 참고하고, 캐릭터·에셋은 전부 오리지널 디자인으로 제작.

## 수직 슬라이스 범위 (첫 빌드 — 1~10라운드 구간 테마)
- [x] 기획 (이 파일)
- [ ] 플레이어 이동 + 대시
- [ ] 먹이 2종 스폰 (하피, 사티로스 테마) + 삼킴/성장
- [ ] 포식자 1종 + 게임 오버
- [ ] 배고픔 게이지 + HUD (점수/레벨)
- [ ] 타이틀 → 플레이 → 게임오버 화면 전환
- [ ] 임시 에셋 (character-design 스킬로 생성, 나중에 교체 가능)
