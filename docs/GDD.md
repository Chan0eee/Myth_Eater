# GDD Lite — Alien Bites (working title)

> 1페이지 기획서. 수직 슬라이스 범위를 정의한다. 변경 시 이 파일을 먼저 고친다.
> 방향: 종스크롤 (세로 화면, 위로 상승)

## 한 줄
배고픈 외계인이 되어 위로 상승하며 먹이를 삼키고 성장하는 모바일 종스크롤 아케이드.

## 코어 루프
1. 화면이 자동으로 위로 스크롤 (외계인은 화면 안에서 자유롭게 이동)
2. 터치 드래그로 외계인을 상하좌우 이동 → 자신보다 작은 먹이(플랑크톤·소형 생물)를 삼킨다
3. 먹을수록 성장 → 더 큰 먹이를 노림. 자신보다 큰 포식자에게 닿으면 게임 오버
4. 배고픔 게이지: 시간이 지나면 감소, 0이 되면 서서히 체력 감소 (굶주림 압박)
5. 런 종료 → 점수/최대 크기/도달 고도 기록 → 재시작 (로그라이트: 나중에 3지선다 업그레이드 추가 예정)

## 조작 (모바일 퍼스트)
- 드래그: 외계인 상하좌우 이동 (상대 드래그, 손가락에 가리지 않게 오프셋)
- 탭: 짧은 대시 (쿨타임 3초) — 먹이 돌진 / 포식자 회피용
- 세로 화면 고정 (portrait), 한 손 플레이

## 성장 단계 (수직 슬라이스)
- Lv1 새끼 (먹이: 플랑크톤) → Lv2 성체 (먹이: 소형 물고기) → Lv3 거대체 (먹이: 중형 생물)
- 각 단계에서 비주얼이 커지고 입이 벌어짐 (스쿼시 앤 스트레치)

## 적/장애물
- 플랑크톤 (먹이, 작음, 느림)
- 소형 물고기 (먹이, 중간, 지그재그 이동)
- 포식자 (위협, 플레이어보다 크면 회피 대상. 플레이어 추적 AI — game-ai 스킬 참조)

## 게임필 (game-feel 스킬 참조)
- 삼킴: 입 쩍 벌림 + 화면 미세 진동 + "꿀꺽" 파티클
- 성장: 레벨업 링 이펙트 + 짧은 슬로모(히트스톱)
- 피격: 화면 흔들림 + 붉은 비네트

## 아트 디렉션 (미정 — 결정 필요)

- 후보 B: 파스텔 벡터 (캐주얼 모바일 감성)
