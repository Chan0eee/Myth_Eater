# GDD Lite — Myth Eater (가제: 신화를 삼키는 자)

> 1페이지 기획서. 수직 슬라이스 범위를 정의한다. 변경 시 이 파일을 먼저 고친다.
> 방향: 종스크롤 (세로 화면, 위로 상승)

## 한 줄
신들에게 계략에 빠져 힘을 잃은 '공허의 포식자'가 신화 속 존재들을 삼키며 힘을 되찾고,
약한 신부터 강한 신까지 판테온을 정복해 올라가는 종스크롤 아케이드.

## 스토리
주인공은 우주의 끝에서 떠돌던 포식자. 제우스의 꾐에 빠져 올림포스의 연회에 초대받았다가
힘을 봉인당한 채 타르타로스 심연에 추방된다. 이제 신화의 존재들을 삼키며 힘을 되찾고,
신들의 전당을 향해 올라간다. 약한 신부터, 마지막엔 신들의 왕까지.
올림포스가 무너지자 이를 지켜보던 아스가르드의 신들이 봉인을 시도하며 라그나로크 편이 열린다.

## 코어 루프
1. 화면이 자동으로 위로 스크롤 (포식자는 화면 안에서 자유롭게 이동)
2. 터치 드래그로 상하좌우 이동 → 자신보다 작은 신화 생물을 삼킨다
3. 먹을수록 성장 → 더 큰 먹이를 노림. 자신보다 큰 존재에게 닿으면 게임 오버
4. 배고픔 게이지: 시간이 지나면 감소, 0이 되면 서서히 체력 감소
5. 스테이지 클리어 → 중간보스 → 보스신 처치 → 다음 스테이지 (판테온을 올라감)
6. 런 종료 → 점수/최대 크기/도달 스테이지 기록 → 재시작 (로그라이트: 나중에 3지선다 업그레이드 추가 예정)

## 조작 (모바일 퍼스트)
- 드래그: 포식자 상하좌우 이동 (상대 드래그, 손가락 가림 방지 오프셋)
- 탭: 짧은 대시 (쿨타임 3초) — 먹이 돌진 / 공격 회피용
- 세로 화면 고정 (portrait), 한 손 플레이

## 성장 단계
- Lv1 심연의 새끼 → Lv2 포식자 → Lv3 신화급 거대체
- 각 단계에서 비주얼이 커지고 입이 벌어짐 (스쿼시 앤 스트레치)

## 동료 뽑기 시스템 (가챠)

외계인은 배고파처럼 뽑기로 캐릭터를 모으고, 뽑은 신이 함께 싸운다.
동료 풀은 **제우스와 반대편에 섰던 신화 속 인물**로 구성 — 스토리(제우스에게 봉인당한 포식자)와 직결된다.

### 동료 로스터 (고증 기반)
| 캐릭터 | 고증 | 등급 | 전투 역할 |
|--------|------|------|----------|
| 프로메테우스 | 인간에게 불을 준 죄로 제우스에게 처벌받은 티탄. 반역의 상징 | 전설 | 화염 오라 — 주변의 작은 적에게 지속 화염 피해 |
| 메티스 | 제우스의 첫 아내. 삼켜지기 전 지혜의 여신 | 전설 | 지혜의 가호 — 성장(경험치) 속도 증가 |
| 티폰 | 백 개의 머리로 제우스를 한때 가둔 유일한 존재 | 전설 | 폭풍 돌진 — 주기적으로 전방 범위 공격 |
| 크로노스 | 제우스의 아버지, 티탄의 왕 | 전설 | 시간 왜곡 — 주변 적 이동 속도 감소 |
| 아틀라스 | 티타노마키아에서 패해 하늘을 짊어진 티탄 | 희귀 | 대지의 방벽 — 주기적으로 실드 생성 |
| 헤라 | 일리아드에서 포세이돈·아테나와 함께 제우스를 묶으려 한 모반 가담 | 희귀 | 공작의 눈 — 먹이 탐지/자석 범위 증가 |
| 포세이돈 | 같은 모반 가담. 바다의 신 | 희귀 | 해일 — 파도 형태 범위 공격 |
| 로키 | 아스가르드의 적, 라그나로크의 도화선 (노르드 편) | 전설 | 분신 — 환영이 함께 공격 (페이즈 2) |
| 펜리르 | 오딘을 삼킬 운명의 늑대 (노르드 편) | 전설 | 광폭화 — 처치 시 공격 속도 증가 (페이즈 2) |

### 전투 방식
- 최대 3명 편성. 플레이어 주변을 공전하며 자동 공격/버프 — "같이 싸우는 느낌"
- 보스를 쓰러뜨리면 해당 보스가 동료 풀로 해금되는 경우도 있음 (쓰러뜨린 적의 영입 — 가챠 게임 단골 문법)

### 뽑기 설계 (페이즈 2에서 수치 확정)
- 재화: '신화의 정수' — 먹이 섭취와 보스 처치로 획득 (과금 재화는 출시 페이즈에서)
- 등급: 일반 / 희귀 / 전설, 천장(픽업 보장) 시스템
- 중복 획득 → 돌파(강화). 스킨은 페이즈 3

## 게임필 (game-feel 스킬 참조)
- 삼킴: 입 쩍 벌림 + 화면 미세 진동 + "꿀꺽" 파티클
- 성장: 레벨업 링 이펙트 + 짧은 슬로모(히트스톱)
- 피격: 화면 흔들림 + 붉은 비네트
- 보스전: 등장 시 이름 자막 + 체력 바 (외계인은 배고파식 연출)

## 아트 디렉션 (확정)
- **볼드 카툰 치비 스타일** (레퍼런스 외계인은 배고파 계열): 굵은 외곽선, 셀 셰이딩, 고채도 컬러, 치비 비율, 글로시 하이라이트.
- 스테이지마다 테마 컬러 (그리스: 대리석+올리브, 지하세계: 어둠+청록 불꽃, 노르드: 설원+오로라).
- ⚠️ IP 주의: 스타일(화풍)만 참고하고, 캐릭터·에셋은 전부 오리지널 디자인으로 제작. 기존 게임의 캐릭터/로고/에셋을 모방·복제하지 않는다.

## 페이즈 2 (나중)
- 스테이지 시스템 + 중간보스/보스전 (위 로스터 순서대로)
- 보스별 고증 기반 공격 패턴 (아레스: 돌진, 메두사: 석화 시선, 토르: 번개 낙뢰, 로키: 분신 등)
- 동료 뽑기 시스템 (위 로스터, 뽑기 확률/천장 수치 확정)
